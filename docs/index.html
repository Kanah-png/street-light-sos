Edge Architecture & Tech Stack

Designed to run locally on low-power streetlight embedded hardware without requiring expensive cloud bandwidth for video streams.

  • Perception Engine: OpenCV + Ultralytics YOLOv8 for sub-30ms object detection and pose estimation.
  • Alert Dispatcher: Integrated Twilio SMS & Voice Calling client paired with custom REST endpoints.
  • Embedded Hardware: Designed for NVIDIA Jetson Orin Nano, Raspberry Pi 4/5, or RTSP CCTV feeds.
  • Live Web Server: Built with FastAPI + Uvicorn background threads for real-time telemetry.

How to Run locally

01

Clone Repository

02

Install Dependencies

pip install -r requirements.txt
03

Launch System

python main.py --source 0
